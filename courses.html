Not Sure Where to Start?

We'll help you choose your first track

Choosing a first skill can feel overwhelming. Here's our simple advice:

  • Love logic and puzzles? Start with Python or Cybersecurity.
  • Love building and seeing results? Start with Web Development.
  • Love numbers and stories? Start with Data Science.
  • Curious about how systems work? Start with Cloud Computing.
  • Creative thinker? Start with UI/UX or Game Development.
